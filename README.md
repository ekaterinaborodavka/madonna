# DJ Madonna — Official Website

Personal promo website for **DJ Madonna**.

## Features

- Multilingual interface using **i18next**
- Responsive adaptive design for all screen sizes
- Gradient gold typography
- Header with name and image
- Performance formats and technical riders
- Video gallery
- Social links to Instagram and Telegram

## Tech Stack

- **React (TypeScript)**
- **Vite**
- **i18next**
- **CSS Flexbox / Media Queries**

## Local Setup

```bash
git clone https://github.com/ekaterinaborodavka/madonna.git
cd madonna
npm install
npm run dev
```

## Live Website

The website is deployed via **Vercel**: [https://djmadonna.vercel.app](https://djmadonna.vercel.app)
